# Однократная установка

Скопируйте папку `alla-analysis` в `.qwen/skills/` проекта автотестов. Скилл обнаруживается Qwen Code по `SKILL.md`; в актуальной версии его можно открыть через `/alla-analysis`, затем передать номер прогона, либо написать «разбери прогон 12345».

Из корня проекта, используя установленный Python **3.11 или новее**:

```sh
python3.11 -m venv .qwen/skills/alla-analysis/.venv
.qwen/skills/alla-analysis/.venv/bin/python -m pip install -r .qwen/skills/alla-analysis/requirements.txt
```

На Windows используйте `py -3.11 -m venv` и `.venv\Scripts\python.exe`. Вместо `python3.11` допустим другой установленный Python >=3.11. Окружение автотестов не изменяется. При недоступности индекса пакетов используйте настроенное в компании зеркало pip; не отключайте проверку сертификатов. Для корпоративного CA HTTPX поддерживает окружение `SSL_CERT_FILE`.

Настройте переменные окружения `ALLURE_ENDPOINT` и `ALLURE_TOKEN`, либо создайте `.env` в корне проекта:

```dotenv
ALLURE_ENDPOINT=https://testops.example.com
ALLURE_TOKEN=<ваш API token>
```

Не перезаписывайте существующий `.env`; добавьте только отсутствующие параметры. Переменные окружения имеют приоритет. Токен не передавайте в чат или аргументы команд. `.env`, окружение скилла и отчёты должны быть исключены из Git; проверьте правила проекта перед добавлением файлов. Сервер Alla, БД и ключ модели не нужны: используется активная модель Qwen Code.

Результаты находятся в `reports/alla/<launch_id>/<timestamp>-<unique_id>/`. Каждый запрос создаёт новую папку; исходные тесты не меняются. Хранение локальное, автоматического удаления и базы знаний нет. Для продолжения передайте агенту путь к уже созданной папке.

Лимиты v1: до 1000 активных failed/broken результатов; 10 MiB скачанных данных на вложение; 64 KiB извлечённого лог-контекста на тест; полные скачанные текстовые вложения доступны отдельным чтением. Вложения сверх лимита помечаются `truncated`. Если сервер отклоняет токен, недоступен или меняет список результатов при пагинации, подготовка завершается ошибкой, а не частичным «успешным» отчётом.

Пакет содержит только чтение TestOps; единственный POST используется для обмена API token на JWT. Инструкции скилла не предоставляют разрешений поверх обычных настроек безопасности Qwen Code.

Проверка установки:

```sh
.qwen/skills/alla-analysis/.venv/bin/python .qwen/skills/alla-analysis/scripts/alla.py --help
```

Для разработки: установите `requirements-dev.txt` и выполните `python -m pytest tests` из папки скилла. [Сценарии проверки модельного анализа](evaluation.md) выполняются отдельно в Qwen Code: Python-тесты проверяют данные и контракт, но не доказывают качество выводов модели.
