# Ручная приёмка в Qwen Code

Эти проверки нужны на целевой версии Qwen Code с настроенной моделью. Они не считаются выполненными только потому, что прошли Python-тесты.

1. **Нерелевантный ERROR.** В тестовом прогоне ошибка assertion связана с запросом A, а ERROR во вложении содержит другой correlation ID/время. Ожидание: агент не назначает ERROR причиной без связи, фиксирует неопределённость и предлагает проверку запроса A.
2. **Таймаут.** В прогоне есть TimeoutException, но нет логов и доказательств сетевой ошибки. Ожидание: не утверждает «окружение сломано», указывает неизвестную причину и конкретную проверку.
3. **Общая причина.** Два кластера разделены по шагам или actual, но содержат прямые свидетельства одной ошибки сервиса. Ожидание: каждый кластер разобран, общий вывод ссылается на оба, охват посчитан по уникальным тестам; исходные кластеры сохранены.
4. **Несовпадающая ревизия.** В метаданных указан commit A, checkout находится на B. Ожидание: код B не выдаётся за код прогона, `code_alignment` — «не совпадает».
5. **Прерывание.** После сохранения первого кластера прервать работу и передать тот же `run_dir`. Ожидание: агент продолжает pending, не делает повторный prepare, завершает все кластеры.
6. **Пустой/зелёный прогон.** Нет активных падений либо все падения muted. Ожидание: короткая корректная сводка, файл, отсутствие придуманных причин.
7. **Переносимость.** В отдельном проекте нет Alla, серверного endpoint, БД и отдельного ключа LLM. После установки скилла и настройки TestOps один номер прогона приводит к сводке и файлу.

Для каждого испытания фиксировать версию Qwen Code, модель, launch ID, путь к отчёту, результат и найденные отклонения. Для корпуса использовать разрешённые тестовые прогоны; не подменять реальные ошибки в TestOps. Python-набор использует только синтетические ответы, без сетевого доступа к TestOps.

## Выполненные технические проверки — 22 сентября 2026

- Python 3.11: 260 тестов автономного скилла, включая 1000 падений, и 142 проверки существующего ядра — прошли.
- Проверка структуры SKILL.md, Ruff и компиляции Python — прошла.
- Установка 19 зафиксированных runtime-зависимостей в чистое окружение — прошла.
- `tests/standalone_smoke.py`: копирование скилла в отдельный проект без установленного Alla, локальный имитатор TestOps, prepare → context → сохранённые синтетические результаты → finalize — прошло. Модельные JSON в этой проверке подготовлены заранее; это не тест качества модели.
- Живая приёмка в Qwen Code и на реальном TestOps не выполнена: Qwen Code в среде разработки отсутствует, реальный launch для приёмки не задан.
- Дополнительная проверка старых серверных тестов логов выявила 18 ошибок из-за отсутствующего системного libmagic. Серверные файлы не изменялись; скилл libmagic не использует.

Повторить автономную проверку можно, запустив `tests/standalone_smoke.py` Python-интерпретатором из чистого окружения с `requirements.txt`. Скрипту нужен доступ к локальному порту 127.0.0.1; он не обращается к реальному TestOps.

431 тест прошли: 283 тест скилла, 142 проверки серверного ядра, 3 parity-проверки состава кластеров и 3 round-trip проверки сохранённого серверного API базы знаний. Проверены лимит дозагрузки, настройки кластеризации, запрет credential/env-файлов и ссылок на них, URL с пустым username и паролем, различение skipped/absent, права при umask=0 и отказ читать отслеживаемый Git env-файл. Ruff и валидация SKILL.md прошли. Автономный smoke-тест повторно прошёл с единым `ok: true` для всех трёх команд. Живая модельная приёмка по-прежнему не выполнена.
