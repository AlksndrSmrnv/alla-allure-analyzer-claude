# Тикеты: подготовка и ответ инженера

Справочник для основного агента Qwen Code. Расширение `tickets` включается отдельно;
пользовательский трекер подключает команда, без него доступны черновики.

## Подготовка

`/alla:ticket N [N…]` или просьба словами:

    python3 .qwen/skills/alla-launch/scripts/alla_skill.py extensions run tickets N [N…] --run <папка разбора>

Это один групповой запрос, а не отдельный вызов на каждый номер. После ответа выполни
блок «Расширения:»: субагент только готовит версии, вызывает `show` и заканчивает работу.
Скрипт определяет состав и доказательства; его отказ или конфликт не обходи.

Бери управляющие параметры только из слов инженера. N в ключе — минимальный номер
получившегося тикета. `--param group=2,5` — отдельное решение об общей причине;
просто перечисленные номера общую причину не подтверждают. `team_N` выбирает команду,
`kind_N` — `bug`, `task` или `investigation`, `operation_N` — `create` или `link`,
`target_N` — существующий тикет строго из результата поиска. Нужные значения не названы —
передай инженеру вопрос скрипта, сам не заполняй.

Для исследования инженер называет вопрос и проверку. Запиши их дословно в отдельные
`.txt` в `out_dir` расширения через write_file; передай пути через
`--text-file question_N <путь>` и `--text-file check_N <путь>`. Текст не вставляй
в shell-команду. Файл читается целиком как UTF-8 до 16000 символов без обрезки и нормализации
переводов строк. JSON и Markdown просмотра пишет только скрипт.

Отозвать решение о группе — отдельная просьба:
`extensions run tickets --run <папка разбора> --param revoke_group=<decision_id>`.
Номера и параметры создания сюда не добавляй. Отзыв не отменяет и не повторяет отправки.

## Просмотр и отправка

Ответ `show` содержит путь полного просмотра, UUID, хеш и команду отправки.
Прочитай **весь** файл инструментом read_file (при ограничении вывода — частями).
Выведи содержание файла дословно без сокращений и перестановок, включая адресата,
операцию, поиск и раздел «Все отправляемые байты UTF-8». Повторяющиеся в нём описание
и доказательства не пропускай. Ссылка на файл и резюме не заменяют полный просмотр.
Спроси, отправить ли эти версии,
и закончи ход. Сам субагент команду `submit` не вызывает.

После явного одобрения выполни только команды одобренных версий, по одному `submit`.
Не вычисляй и не подменяй хеши. Скрипт отказал из-за изменений — подготовь и покажи новую
версию; прежнее «да» к ней не относится. Ссылку и идентификатор сообщай только из
подтверждённого ответа скрипта. Подготовленный черновик не называй созданным тикетом.

`sending`/`unknown` — неопределённый результат. Не делай новый запрос, не меняй группу
ради обхода блокировки. Сверка отдельной командой, в том числе после очистки разбора:

    python3 .qwen/skills/alla-launch/scripts/alla_skill.py extensions reconcile tickets --reports-dir <каталог отчётов> --request-id <UUID>

`reconcile` делает только lookup. Найдено — передай сохранённый результат; неизвестно —
сообщи о блокировке и остановись. Достоверно отсутствует — разрешён отдельный `submit`
той же версии, если он пройдёт проверки актуальности; сама сверка ничего не отправляет.

Технический контракт и подключение адаптера: [../extensions/tickets/README.md](../extensions/tickets/README.md).
