Вызови скилл alla-launch (инструмент skill) и действуй по разделу «7. Расширения»: пользователь
просит разобрать проблему по коду приложения (расширение sut-code).

Запрос: {{args}}

Первое число — номер проблемы; нет его — спроси. Ссылка на git (https://…, ssh://…,
git@…) — параметр `--param repo=<ссылка>`; другое слово — ревизия, на которой был стенд:
`--param ref=<значение>`. Папку разбора найди по разделу «Слэш-команды» скилла.
