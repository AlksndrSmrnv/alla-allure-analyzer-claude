Вызови скилл alla-launch (инструмент skill): пользователь прямо просит проверить законченный
разбор. Действуй по разделу «6. Проверка разбора — только по прямой просьбе». Папка разбора — из
этого сеанса, а если её нет — по разделу «Слэш-команды» скилла.
