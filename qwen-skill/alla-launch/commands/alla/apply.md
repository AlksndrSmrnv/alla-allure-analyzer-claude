---
description: Показать и применить правку автотеста для проблемы N из разбора (скилл alla-launch)
argument-hint: <номер проблемы>
disable-model-invocation: true
---
Вызови скилл alla-launch (инструмент skill) и действуй по разделу «4. После отчёта: правки
автотестов» для проблемы {{args}}: выполни `apply` без `--yes`, покажи diff и спроси, применить
ли правку. Без явного «да» правку не применяй.

Папку разбора найди по разделу «Слэш-команды» скилла. Если номер проблемы не указан — спроси.
