# Проверка расширения tickets — 2026-10-28

Реализовано отключённое по умолчанию расширение с пользовательским адаптером трекера.
Проверки использовали синтетический TestOps и локальный SQLite-адаптер; настоящий
трекер и его API не подключались.

- Ruff: без замечаний. Mypy: без ошибок, 84 исходных файла.

Проверены реальные дочерние процессы адаптера, потеря ответа после commit,
идемпотентность, внешний link, неопределённый результат, достоверное отсутствие,
сверка после clean, конкурирующее назначение UUID, изменение показанных байтов,
проекция выбранных проблем, конфликты и отзыв групп, источники и многострочные входы.
Отдельный тест завершает процесс скилла до первого обращения адаптера к SQLite:
унаследованная блокировка не позволяет сверке объявить отсутствие, пока адаптер жив.

## Непроверенное

Пользовательский адаптер нужно проверить на тестовом проекте настоящего трекера,
особенно его гарантии идемпотентности и authoritative_absence. Скрипт проверяет байты
и происхождение цитат; полный показ и человеческое одобрение остаются обязанностью
сценария Qwen, а правильность диагноза оценивает инженер.

Дополнительная независимая проверка только инструкций с чистым контекстом не выполнена:
агент завершился до чтения файлов из-за лимита использования. Независимая проверка
кода и перечисленные реальные сценарии Qwen выполнены.
